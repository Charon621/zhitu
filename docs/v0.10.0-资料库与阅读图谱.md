# 织图 v0.10.0：手写笔记与阅读图谱

新增独立资料库，把导入文件从对话附件扩展为可整理、校对、持久化的阅读材料。原始对话流水不受整理影响。

## 使用

左栏打开「资料库」，选择手写笔记或书籍入口，也可拖入文件。导入仅在本机保存、提取；确认整理范围和预计用量后，点击开始才会把资料发送给设置中的 AI 服务商。

手写笔记支持 PNG、JPG、WebP 和扫描 PDF。设置中须开启视觉识别并填写支持图片的视觉模型。识别后按主题生成分类笔记，点击原文依据可核对摘录。「原文与校对」可保留修改后的转录，下一次整理仅重新分类。分类、标题和内容均可编辑。

书籍建议使用可提取文字的 EPUB 或 TXT，也支持 Word、PDF。EPUB 根据 [W3C 定义的 spine 阅读顺序](https://www.w3.org/TR/epub-33/)处理章节，逐段读取全文范围。人物图显示带标签的关系；剧情图将人物、事件与剧情顺序连接起来，下面提供时间线和可用键盘选择的列表。阅读范围滑块隐藏后续人物、事件、关系，搜索可聚焦具体人物或剧情。图谱可导出 PNG，笔记及剧情可导出 Markdown。

每份资料独立保存原件、转录、结果和检查点。离开页面仍可继续，停止和重启后不会重发已完成片段。重新整理时保留此前结果及其原文来源，新结果成功后再替换。全部数据备份、笔记 ZIP 包均包含资料库整理结果。

## 验证范围

- 旧功能：全量隔离验收，真实数据库哈希在验证前后保持不变，具体检查数以当次报告为准。
- 资料库后台：26 项通过，覆盖 EPUB 章节顺序、整段覆盖、截断 JSON、重启续接、人物端点验证、原文证据过滤、照片与扫描 PDF 识别链路、校对、取消、备份。
- 实际 Electron 界面：22 项通过，覆盖导入、用量、分类、手改持久化、原文校对、Markdown / PNG 实际落盘、人物图、剧情图、防剧透、搜索、深色、900 像素窗口及重复导入。
- 截图、报告、安装包统一放在 `E:\CodexOutputs\织图\2026-09-30-手写笔记与书籍关系图`。

自动化使用合成短书、样例图片 / 扫描页以及本机测试模型。它证明文件、请求、状态、落库、图谱和导出的操作链路可用，不证明真实手写 OCR 准确率，也未使用《百年孤独》全文做真实性评估。原文摘录验证只证明摘录存在，AI 的人物理解、同名消歧和剧情概述仍需人工核对。

## 当前限制

单文件 50 MB；最多同时整理两份资料。一次视觉识别最多 200 页。PDF 原生文字提取限前 200 页，后续未提取页会列入视觉识别计划，请检查用量并选择范围。EPUB / 文档最多提取 200 万字；受保护 / 图片型 EPUB 会提示无法读取。图谱上限为 300 人物、3000 事件、3000 关系，超限中止并保留检查点。

资料库分类笔记保存在独立的资料结果中，可从资料库编辑、检索和导出；现有「笔记」「地图」继续展示对话派生的知识卡片。点击「带着资料聊」会打开对应场次并选中原件，之后的对话仍走现有笔记抽取流程。

数据库升级为 v8。旧程序不支持 v8 数据库；降级前应恢复升级前的数据备份。源码改造前副本保存在交付目录的「改造前源码」。本轮自动化未升级或改写用户真实数据库。
