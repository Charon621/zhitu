# 织图 v0.9.0 更新与验证

2026-09-26，围绕完整现有功能进行可用性检查和界面改造。

## 界面与操作

- 统一纸白、石墨色与灰蓝强调色；移除笔记块彩色竖条和引用竖条，使用排版、留白及细分隔线表达层级。
- 重排学习入口、导航、笔记、复习、本周回顾及弹窗。左侧常用操作固定在底部，历史列表单独滚动。
- 小于 1150px 时按需展开本场笔记，提供关闭按钮与 Esc；保留专注阅读。
- 全局焦点轮廓、弹窗焦点约束与背景隔离，恢复关闭前的焦点；尊重减少动画的系统偏好。
- 修复深色地图标签和深色主按钮文字对比度，验证最小窗口没有页面横向溢出。

## 功能修复与补齐

- 回复断流明确报错，保留当前页面的部分内容并恢复原问题到输入框；停止或新建场次后，旧流回调不会串入新场次。
- 上游 SSE 支持尾行无换行，缺少完成标志或空正文不会被静默当作成功；客户端支持拆分 CRLF，避免终止回调重复触发。
- 快速切换学习场次时忽略迟到请求；草稿按场次保留在当前运行内存中。退出应用后的草稿恢复不在本次实现范围。
- 新增最近 50 场学习记录按标题查找，左栏仍展示最近五场。
- 补齐笔记置顶/取消置顶、标题与内容筛选、清除筛选；修复搜索跳转被默认第一张笔记覆盖的问题，以及循环父子关系导致大纲无根节点的问题。
- 搜索显示真实加载状态，支持方向键选择、Enter 打开及 Esc 关闭。
- 设置保存失败显示可见错误，服务商密钥状态查询防止迟到结果覆盖；修改内容后撤销过时的“已保存”提示。
- 地图增加缩放、适应窗口、筛空提示和尺寸变化处理；复习计划读取错误可见，下一题失败时不会重新提交上一题。
- Markdown 改为同步记忆化渲染，移除 effect 内 flushSync。外部链接限制 HTTP/HTTPS，阻止页面被外部导航替换。
- 验证使用每次新建的独立数据目录，不再按 Electron 路径结束已有应用进程。
