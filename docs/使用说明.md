# 织图 · 使用说明

> 这份是给你和你的朋友看的。不需要任何技术背景。
> 遇到问题先看第七节"出问题了怎么办"。

---

## 一、这是什么

一个陪你自己探索的电脑软件。

你可以从一个问题开始，随便问、随便跑偏。软件会保存对话，并在回答结束后后台整理笔记。点「今天到这儿」可收起已经讲清的线，没讲完的下次继续；左侧「地图」可查看知识点之间的连线。

**它跟直接开个网页问 AI 有什么区别？**

软件会保留你的对话，关掉再打开还能接着看。右侧笔记卡片会把一轮对话里新增的知识压缩出来，地图能把这些点之间的关系画出来。

## 二、怎么装

1. 拿到 **`织图-安装包-0.9.2.exe`**
2. 双击它
3. 如果 Windows 弹出一个蓝色的框写"Windows 已保护你的电脑"——
   **这是正常的**，因为软件没有花钱买数字签名。点「更多信息」，再点「仍要运行」
4. **它会让你选装到哪个目录**（默认装在当前用户目录，不需要管理员权限）
   - 直接点「安装」就用默认位置
   - 想换地方就点「浏览」选一个，比如 `D:\软件\织图`
5. 装完会自己打开，桌面上也会出现一个图标

**不会删你的东西，也不会改你的系统设置。**

### 装完之后，怎么找到它

三个入口，随便用哪个：

| 方式 | 位置 |
|---|---|
| **桌面图标** | 桌面上的「织图」 |
| **开始菜单** | 开始菜单里搜「织图」 |
| **直接路径** | 你安装时选的那个目录里的 `织图.exe` |

**默认安装位置**（没改的话）：

```
C:\Users\你的用户名\AppData\Local\Programs\zhitu
```

> `AppData` 是隐藏文件夹，在文件资源管理器里看不到。
> 想查看就把这一行粘到资源管理器的地址栏回车。
> **也可以右键点桌面图标 →「打开文件所在的位置」，直接跳过去。**

### 怎么卸载

- 开始菜单搜「织图」→ 右键 → 卸载
- 或者到安装目录里双击 `Uninstall 织图.exe`

**卸载不会删除你的学习数据**（这是故意的，方便你以后重装或用新版覆盖安装）。
要彻底清掉数据，见第五节。

## 三、第一次打开：两步向导

### 第 1 步：选一个 AI 服务商

这些是提供 AI 能力的公司。你选哪家，对话就发给哪家，费用也付给哪家。

**建议就选默认的 DeepSeek**——便宜（日常用一天几毛钱）、中文好、国内直接能用、注册简单。

以后想换，随时在设置里改。

### 第 2 步：粘贴密钥

所谓的"密钥"（API Key）就是一张电话卡，用来证明"是我在打电话，费用记我账上"。

怎么拿：
1. 点界面上的「去哪里申请密钥 →」，会打开服务商的网站
2. 注册、登录
3. 找到"API Keys"或"密钥管理"，创建一个
4. **复制那一串 `sk-` 开头的字符**，粘回软件里
5. 点「测试连接」

看到 **「✓ 连接成功」** 就说明通了。

> **关于安全**：密钥保存在你这台电脑上，能加密时会使用 Windows 的加密功能。
> 连接 AI 时，密钥会发送给你选择的服务商；软件的作者不会收到它。

测试成功后点「开始使用」。软件不会问你“现在是什么水平”。

随后会看到开始卡片。你可以输入一个领域名，选“偏原理”“偏动手”或“随便看看”，让 AI 挑三个具体问题；也可以直接点一个示例问题，它会自动成为第一句话。已有具体问题时，点“我有具体问题，直接提问”即可打开输入框。也可以把资料拖进中间区域，或点卡片上的选文件入口；文字资料解析完成后，软件会自动从它开始提问。

## 四、怎么用

### 基本操作

| 想干什么 | 怎么做 |
|---|---|
| 说话 | 在下面的框里打字，按 **Enter** 发送 |
| 换行 | 按 **Shift + Enter** |
| 开始新的一段学习 | 点左上角「＋ 新的一场」 |
| 换服务商/换模型/改密钥 | 点左下角「⚙ 设置」 |
| 修改笔记 | 对话结束后在右侧卡片点「改」或「删」；设置里可以重算，默认「重算（保留现有卡片）」只刷新内容，不会改动你调好的分卡 |
| 找回以前的学习 | 左栏「最近的学习」列出最近 5 场；点「查看学习记录 →」可以按标题查找最近 50 场 |
| 给一场改名 | 学习记录里点「改名」，改完回车或点保存 |
| 收起一场但不想删 | 学习记录里点「归档」。数据全留着，只是从列表里收起来，随时点「恢复」 |
| 彻底删掉一场 | 学习记录里点「删除」。**默认是「移入回收站」**，30 天内可以恢复，删完还有一条 10 秒的「撤销」；想真正抹掉就点「彻底删除」，需要亲手输入"删除"两个字。两种都会先告诉你**会删掉多少对话、几个知识点，以及哪几个知识点会留下** |
| 批量删掉好几场 | 学习记录里勾选每一行前面的方框，再点批量条上的「移入回收站」；一次可撤销 |
| 从回收站找回 | 学习记录上方的「回收站」标签页，找到那一场点「恢复」；那里也能看到占用和自动清理时间 |
| 导入资料 | 点输入框旁「添加资料」、把文件拖进中间区域，或在输入框里粘贴图片 |
| 暂时不在提问中使用资料 | 点资料 chip 上的 ×；原件仍留在本场 |
| 删除资料原件 | 未被对话或笔记引用时可点「删」；已引用的原件会受保护 |
| 找回学过的内容 | 点左栏「搜索」，输入关键词，可打开知识点、对话原文或资料 |
| 复习知识点 | 点左栏「复习」，从到期知识点生成应用题，回答后查看反馈 |
| 导出学习记录 | 点左栏「导出」，选择全部笔记、当前对话或全部数据备份 |
| 回到上次的学习 | 左栏「最近的学习」列出最近五场，点标题直接打开 |
| 暂时不想被引导 | 对话顶部切到「自由」，AI 只回答问题，不主动给下一步 |
| 调整解释多少 | 设置里拖动「讲解深度」，选择少解释、适中或多解释 |

图片和扫描版 PDF 需要在设置中开启「视觉识别」，并选择支持图片的模型，可能增加 API 费用。文字版 PDF 可按页引用；扫描页的转录和引用应点击来源回看原件。PPT 当前只提取文字，图表和排版会显示“部分提取”，不要依赖它回答图表细节。每个文件最多 50 MB，每场最多 20 个文件。

### 怎么问比较好

**想了解一个大领域时，直接在开始卡片填领域名。** 软件会先给三个具体问题，不会一下子抛出完整目录。

**问一个具体到能立刻开讲的：**

- ❌ 我想学 AI
- ✅ 神经网络到底是怎么"学"的？
- ✅ 为什么 AI 能看懂一句话是什么意思？
- ✅ 我听说 RAG 能解决胡说的问题，它是怎么做到的？

**顺着好奇心走就行。** 你从一个问题问到另一个问题，哪怕问到跟开头毫无关系的地方也没关系——
对话会保存下来；点左侧「地图」能看见节点连线，右侧「未收线」可以接着上次停下的问题继续聊。

## 五、你的东西存在哪

打开「⚙ 设置」，拉到最下面，有一行**数据目录**，长这样：

```
C:\Users\你的用户名\AppData\Roaming\zhitu
```

里面最重要的是 **`zhitu.db`** 这一个文件。**你学过的所有东西都在里面。**

- **想备份**：先退出软件，再把整个数据文件夹拷到 U 盘
- **想换电脑**：先退出两台电脑上的织图，再复制整个数据文件夹
- **卸载软件不会删数据**（方便你以后重装）。想彻底清掉，手动删那个文件夹

另外，`logs\app.log` 是出错记录。软件打不开的时候，把里面的内容发给开发者，能帮上大忙。

## 六、花多少钱

**软件本身免费。**

你付给 AI 服务商的钱，直接记在你自己的账号上。日常学习大概：

- 一场半小时的学习（几十轮对话）：**几分钱到一两毛**
- 一个月每天用：**大概几块到几十块**，取决于你选的模型和聊得多不多

想省钱就在设置里换成便宜模型。便宜的模型对"陪着聊"这件事完全够用。

## 七、出问题了怎么办

| 现象 | 原因 | 怎么办 |
|---|---|---|
| **"密钥无效或已过期"** | 密钥打错了，或者被服务商停用了 | 设置里重新粘一次，注意别多复制空格。还不行就回服务商网站重新创建一个 |
| **"账户余额不足"** | 账号里没钱了 | 去服务商网站充值 |
| **"连不上服务器"** | 网络问题，或者公司网络挡了 | 换个网络试试（比如用手机热点）。如果公司网络需要代理，目前软件还不支持设置代理，这是个已知缺口 |
| **"接口地址或模型名不对"** | 设置里选错了 | 设置里换个模型试试。有些模型要单独申请开通 |
| **"请求太频繁或超出额度"** | 问得太快了 | 等十几秒 |
| **软件一闪就没了 / 打不开** | 出错被拦住了 | 打开数据目录里的 `logs\app.log`，把内容发给开发者 |
| **AI 回复很慢** | 模型在思考，或者网络慢 | "正在想…"出现的时候它确实在工作，等一会儿。特别慢可以点「停止」，换个模型 |
| **右侧暂时没有笔记** | 这一轮可能没有新增知识，或者后台整理还没结束 | 等几秒；若始终为空，可在设置里点「重算（保留现有卡片）」 |

## 八、现在能做什么、还不能做什么

**能做：**

- ✅ 跟 AI 正常对话，边说边聊
- ✅ 所有对话自动存下来，关掉再打开还在
- ✅ 配置服务商和密钥，随时更换
- ✅ 显示"当前这一场"的标题
- ✅ 从领域生成三个入口问题，或直接点示例问题开始
- ✅ 自动生成笔记卡片，并允许手改、删除、置顶、重算（可保留你调好的分卡）
- ✅ 导入文字、代码、PDF、Word、PPT、Excel 与图片；支持资料检索和原件预览
- ✅ 复习应用题、全局搜索和三种导出
- ✅ 最近五场、未收线主页面、深色模式、讲解深度与快捷键
- ✅ 专注阅读、本周回顾、笔记节点大纲
- ✅ 学习记录管理：改名、归档、两级删除（回收站 30 天可恢复 / 彻底删除要二次确认）、批量删除、10 秒撤销

**还不能做（正在做）：**

- ⬜ PPT 图表与排版的视觉识别；目前只提取幻灯片文字
- ✅ 未收线清单（跑偏了没走完的路）—— 第 3 步
- ✅ 笔记页 —— 第 4 步
- ✅ 知识地图（看到点和点之间的连线）—— 第 5 步
- ✅ 复习、导出和搜索 —— 第 6 步
- ✅ 界面打磨 —— 第 7 步
- ⬜ 设置代理
- ✅ 左栏列出最近五场；更早的内容可以搜索

右侧栏会显示本场笔记和最多五条未收线；左侧「笔记」可以展开节点树查看完整卡片。

## 九、三个小提醒

1. **想学一个大领域，就填在开始卡片里。** 它会帮你缩成具体问题。
2. **一次别聊太久。** 二三十分钟就停一停，扫一眼右侧卡片；如果 AI 记错了，直接改掉或删除。
3. **觉得哪里别扭，直接说。** 这是自己人用的软件，你的抱怨比任何功能建议都值钱。
